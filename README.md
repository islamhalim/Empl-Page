# مستخرج بيانات الموظفين

موقع عربي بسيط لاستخراج بيانات الموظفين من نصوص البريد الإلكتروني وتصديرها إلى Excel.

## المميزات
- لصق نص البريد الإلكتروني أو أي نص يحتوي على بيانات الموظفين.
- استخراج الاسم، رقم الهاتف، المسمى الوظيفي، والبريد الإلكتروني.
- دعم تسميات عربية وإنجليزية شائعة.
- تعديل البيانات مباشرة داخل الجدول.
- إضافة صفوف يدوياً وحذفها.
- تنزيل النتائج بصيغة `.xlsx`.
- المعالجة تتم داخل المتصفح ولا يتم إرسال النص إلى خادم.

## التشغيل محلياً
افتح `index.html` في المتصفح. يحتاج تحميل مكتبة Excel وخط Cairo إلى اتصال بالإنترنت.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع الملفات `index.html` و`style.css` و`app.js` و`README.md` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. من **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر ظهور رابط الموقع في صفحة Pages.

## حدود الاستخراج
الاستخراج الحالي يعتمد على قواعد وأنماط نصية، وليس نموذج ذكاء اصطناعي. تكون النتائج أفضل عندما تكون البيانات مكتوبة بصيغة واضحة مثل:
- الاسم: أحمد محمد
- رقم الهاتف: 01012345678
- المسمى الوظيفي: مهندس نظم
- البريد الإلكتروني: ahmed@example.com

قد تحتاج إلى مراجعة النتائج وتصحيحها، خصوصاً إذا كانت الرسالة تحتوي على عدة أشخاص أو بيانات غير معنونة.
